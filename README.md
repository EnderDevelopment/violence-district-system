# Violence District System

Manage player entry and exit in a violence district with notifications and database logging.

## Features

- Player entry and exit notifications
- Database logging of player activity in the violence district

## Requirements

- FiveM server with ESX Legacy framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start violenceDistrictSystem` to your server.cfg

## Usage

The script will automatically detect when players enter or exit the violence district and provide notifications. Player activity is logged to the database.

## Configuration

Edit the `config.lua` file to set the violence district coordinates, radius, and notification messages.
